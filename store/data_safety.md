# Media Diary — безопасность данных

## Разрешения

Разрешения приложения:
- INTERNET

Опасные разрешения:
- не используются

## Аккаунт

Приложение не требует регистрации.
Приложение не собирает имя, номер телефона, email, контакты, геолокацию, фото, данные микрофона, камеры или платежные данные.

## Пользовательские данные

Пользователь может создавать локальные данные:
- коллекция фильмов и сериалов;
- статус просмотра;
- личная оценка;
- дата просмотра;
- личная заметка.

Эти данные сохраняются локально на устройстве в базе данных приложения.

## Передача данных

Приложение отправляет поисковые запросы во внешний API с информацией о фильмах, сериалах, мультфильмах и аниме.

Приложение не отправляет личные заметки, личные оценки, даты просмотра или локальную коллекцию на сервер разработчика.

## Резервное копирование

Если на устройстве включено резервное копирование Android, локальная база приложения может быть включена в системное резервное копирование или перенос данных на новое устройство.
