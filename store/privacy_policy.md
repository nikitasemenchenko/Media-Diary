# Политика конфиденциальности Media Diary

Дата вступления в силу: 29.04.2026

Media Diary — мобильное приложение для ведения личной коллекции фильмов, сериалов, мультфильмов и аниме.

## Какие данные сохраняет приложение

Приложение может сохранять на устройстве пользователя следующие данные:

- добавленные в коллекцию фильмы, сериалы, мультфильмы и аниме;
- выбранный статус просмотра;
- личную оценку;
- дату просмотра;
- пользовательские заметки.

Эти данные хранятся локально на устройстве пользователя в базе данных приложения.

## Регистрация и аккаунты

Media Diary не требует регистрации и не использует аккаунты пользователей.

## Передача данных третьим лицам

Приложение использует внешний API для поиска и загрузки информации о фильмах, сериалах, мультфильмах и аниме.

При выполнении поиска приложение отправляет поисковый запрос во внешний API. Личные заметки, личные оценки, даты просмотра и локальная коллекция пользователя не отправляются разработчику приложения.

## Разрешения приложения

Приложение использует разрешение INTERNET для поиска и загрузки информации о фильмах и сериалах.

Приложение не запрашивает доступ к геолокации, контактам, камере, микрофону, файлам пользователя или SMS.

## Резервное копирование

Если на устройстве включено резервное копирование Android, локальные данные приложения могут быть включены в системное резервное копирование или перенос данных на новое устройство.

## Безопасность

Данные приложения хранятся локально на устройстве. Пользователь может удалить данные приложения средствами Android или удалить приложение с устройства.

## Изменения политики

Политика конфиденциальности может обновляться при изменении функциональности приложения.
